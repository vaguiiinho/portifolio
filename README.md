
## ▶️ Como executar

### Pré-requisitos

Tenha instalado:

- Node.js
- npm
- PostgreSQL
- Docker (opcional)

---

## Frontend

Entre no diretório:

```bash
cd frontend
```

Instale as dependências:

```bash
npm install
```

Execute em desenvolvimento:

```bash
npm run dev
```

---

## Backend

Entre no diretório:

```bash
cd backend
```

Instale as dependências:

```bash
npm install
```

Configure as variáveis de ambiente necessárias.

Exemplo:

```env
DATABASE_URL="postgresql://usuario:senha@localhost:5432/portifolio"
```

Gere o Prisma Client:

```bash
npx prisma generate
```

Execute a aplicação:

```bash
npm run start:dev
```

---

## 🧪 Testes

O backend possui estrutura para testes utilizando Jest.

Execute:

```bash
npm test
```

Para visualizar cobertura:

```bash
npm run test:cov
```

Para testes E2E:

```bash
npm run test:e2e
```
